# mplus founder

**开始前先读 [`../mplus-shared/SKILL.md`](../mplus-shared/SKILL.md)（认证、登录、全局参数）**

## 是什么

仅限创始人（被奇绩投资的企业创始人）使用，只读，只能查自己的资料和关联公司。管理员账号没有此权限。

## 查看帮助

```bash
mplus founder --help
```
